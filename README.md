# Althujoori Real Estate Website

## Local development
```
npm install
npm start
```
Open http://localhost:3000

## Environment variables
- `PORT` — server port (default 3000)
- `ADMIN_PASS` — admin password (default althujoori2025)

## Deploy on Railway
1. Push this folder to GitHub
2. Connect Railway to the GitHub repo
3. Railway auto-deploys and gives you a live URL
